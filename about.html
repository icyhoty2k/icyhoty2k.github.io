About

Ivan Yanev · Bulgaria

I write software on my own, mostly in the evenings, and I publish it under icyhoty2k. What ties it together is not a platform or a language but a preference: programs should start instantly, do the job, and then get out of the way.

How it gets built

QuickImageViewer is about sixty thousand lines of C++ written directly against Win32 and Direct2D, with no UI framework underneath it. That is an unfashionable choice and a deliberate one. A framework would have saved months and cost the thing the whole program is for — the moment between double-clicking a file and seeing it. Speed is not a feature there; it is the product.

The Android side is Java and XML views for the same reason: I would rather know what the code is doing than have it done elegantly somewhere I cannot see.

What I care about

No accounts where an account is not needed. No telemetry phoning home to tell me how you use a picture viewer. Settings that survive a restart. Keyboard shortcuts for everything, because reaching for the mouse is a tax. And software that is finished rather than permanently in progress.

What is next

More Android work, and eventually games. The catalogue is small today; the approach will not change as it grows.
