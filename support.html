Get in touch

Email icyhoty2k@gmail.com for anything, or open an issue on GitHub if the app has a repository. Both reach me; the issue tracker is better because the answer stays visible to the next person with the same problem.

Reporting a bug usefully

What actually helps, in order: what you did, what happened, what you expected. Then the app version — QuickImageViewer shows it in its About box, qIV Remote on its About screen. If a specific file triggers it, that file is worth more than any description of it.

qIV Remote — Android

What it does · Privacy policy · Tester group

It is in closed testing, so the Play listing is invisible until you have joined the test. The three steps are on the front page. It needs Android 13 or newer, and it drives QuickImageViewer on a Windows PC over your own network — though the built-in demo mode runs every screen with no PC at all.
